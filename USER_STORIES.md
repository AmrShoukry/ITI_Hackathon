# User Stories for Item Rental System

## Guest Stories

**As a Guest**, I want to browse listings so that I can see what items are available for rent.

**As a Guest**, I want to search items so that I can find specific items I'm interested in renting.

**As a Guest**, I want to view item details so that I can learn more about an item before deciding to rent it.

**As a Guest**, I want to view owner ratings so that I can assess the reliability of item owners.

## Renter Stories

**As a Renter**, I want to register so that I can create an account and start using the platform.

**As a Renter**, I want to login so that I can access my account and perform renter-specific actions.

**As a Renter**, I want to manage my profile so that I can keep my information up to date.

**As a Renter**, I want to search items so that I can find items I want to rent.

**As a Renter**, I want to filter items so that I can narrow down search results based on my preferences.

**As a Renter**, I want to view item details so that I can evaluate items before requesting to rent them.

**As a Renter**, I want to create booking requests so that I can request to rent items from owners.

**As a Renter**, I want to select rental period so that I can specify how long I want to rent an item.

**As a Renter**, I want to pay online so that I can securely pay for rentals through the platform.

**As a Renter**, I want to pay cash on pickup so that I have an alternative payment method for rentals.

**As a Renter**, I want to track my bookings so that I can see the status of my current and past rentals.

**As a Renter**, I want to view my rental history so that I can review my past rental activities.

**As a Renter**, I want to rate owners so that I can provide feedback about my rental experience.

**As a Renter**, I want to leave reviews so that I can share detailed feedback about owners and items.

## Owner Stories

**As an Owner**, I want to register so that I can create an account and start listing items for rent.

**As an Owner**, I want to login so that I can access my account and perform owner-specific actions.

**As an Owner**, I want to upload my National ID so that I can begin the verification process.

**As an Owner**, I want to submit a verification request so that I can become a verified owner on the platform.

**As an Owner**, I want to create listings so that I can make my items available for rent.

**As an Owner**, I want to edit listings so that I can update item information when needed.

**As an Owner**, I want to delete listings so that I can remove items that are no longer available for rent.

**As an Owner**, I want to upload photos so that I can show potential renters what my items look like.

**As an Owner**, I want to manage availability so that I can specify when my items are available for rent.

**As an Owner**, I want to approve bookings so that I can confirm rental requests from renters.

**As an Owner**, I want to reject bookings so that I can decline rental requests that don't work for me.

**As an Owner**, I want to confirm item return so that I can mark when rented items have been returned.

**As an Owner**, I want to report damage so that I can document any issues with returned items and request compensation.

## Admin Stories

**As an Admin**, I want to manage users so that I can oversee all platform users and their roles.

**As an Admin**, I want to manage roles so that I can define and modify user permissions.

**As an Admin**, I want to approve owner verification so that I can verify legitimate owners on the platform.

**As an Admin**, I want to approve listings so that I can ensure only appropriate items are available for rent.

**As an Admin**, I want to reject listings so that I can remove inappropriate or non-compliant items from the platform.

**As an Admin**, I want to configure categories so that I can organize items into logical groups for easier browsing.

**As an Admin**, I want to configure pricing policies so that I can set rules for how item prices are determined.

**As an Admin**, I want to configure deposit policies so that I can set rules for security deposits.

**As an Admin**, I want to view analytics so that I can monitor platform performance and usage.

**As an Admin**, I want to view reports so that I can generate detailed insights about platform activities.

## Listings Module Stories

**As a User**, I want to create a listing so that I can make my item available for rent on the platform.

**As a User**, I want to update a listing so that I can keep my item information current and accurate.

**As a User**, I want to delete a listing so that I can remove items that are no longer available for rent.

**As a User**, I want to view a listing so that I can see all the details about an item before deciding to rent it.

**As a User**, I want listing approval so that I can ensure only verified and appropriate listings appear on the platform.

## Booking Module Stories

**As a Renter**, I want to select date ranges so that I can specify exactly when I want to rent an item.

**As a User**, I want availability validation so that I can ensure items are not double-booked.

**As a User**, I want conflict detection so that the system can prevent overlapping bookings.

**As an Owner**, I want a booking approval workflow so that I can review and respond to rental requests.

## Payment Module Stories

**As a Renter**, I want to make online payments so that I can securely pay for rentals through the platform.

**As a Renter**, I want to pay cash on pickup so that I have an alternative payment method for when I collect the item.

**As a User**, I want deposit tracking so that security deposits are properly managed and accounted for.

**As a User**, I want deposit release so that I get my deposit back when items are returned undamaged.

**As an Owner**, I want deposit deduction so that I can be compensated for any damage to my items.

## Damage Reports Stories

**As an Owner**, I want to report damage so that I can document issues with returned items.

**As an Owner**, I want to upload evidence photos so that I can provide visual proof of any damage.

**As an Owner**, I want to enter a damage description so that I can explain what happened to the item.

**As an Owner**, I want to specify a deduction amount so that I can request appropriate compensation for damage.

## Reviews & Ratings Stories

**As a Renter**, I want to rate owners so that I can share my experience with the rental process.

**As an Owner**, I want to rate renters so that I can share my experience with renters.

**As a User**, I want reviews to be visible only after return so that feedback is based on completed transactions.

**As a User**, I want one review per booking so that each rental transaction is fairly represented.

**As a User**, I want ratings visible on profiles so that users can quickly assess each other's reliability.

## Owner Verification Stories

**As an Owner**, I want to upload my National ID image so that I can verify my identity.

**As an Owner**, I want my verification status to be tracked so that I know where I am in the verification process.

**As an Admin**, I want to verify owner identities so that I can ensure only legitimate owners list items.

## Admin Analytics Stories

**As an Admin**, I want to see active rentals so that I can monitor current platform activity.

**As an Admin**, I want to see a revenue summary so that I can understand the platform's financial performance.

**As an Admin**, I want to see top rented items so that I can identify popular categories and items.

**As an Admin**, I want to see pending verification requests so that I can manage the owner verification workflow.

## Shared Requirements Stories

**As a User**, I want authentication so that I can securely access my account and protect my personal information.

**As a User**, I want authorization (RBAC) so that I can only access features appropriate for my role.

**As a User**, I want responsive design so that I can use the platform effectively on any device.

**As a User**, I want Arabic language support so that I can use the platform in my preferred language.

**As a User**, I want English language support so that I can use the platform in my preferred language.

**As a User**, I want mobile support so that I can access the platform from my smartphone or tablet.

**As a Developer**, I want REST APIs so that I can build and integrate with the platform programmatically.

**As an Admin**, I want audit logging so that I can track user actions for security and compliance purposes.
